# Diretório de Ingestão de CSVs do VRE

Deposite nesta pasta os arquivos `.csv` exportados pelo sistema **Via Rápida Empresa (VRE)**.

### Instruções Operacionais:
1. Salve o arquivo CSV nesta pasta (`entrada_csv/`) ou na pasta raiz do sistema.
2. O sistema aceita qualquer nome de arquivo com extensão `.csv`.
3. Caso existam múltiplos arquivos nesta pasta, o sistema selecionará automaticamente o arquivo com **data de modificação mais recente**.
4. Como alternativa, você pode arrastar e soltar (Drag & Drop) qualquer arquivo `.csv` diretamente sobre o script `Executar_Triagem.bat`.
5. Após o processamento, os arquivos podem ser mantidos ou arquivados na subpasta `processados/`.
