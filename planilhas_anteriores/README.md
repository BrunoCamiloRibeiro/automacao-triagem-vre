# Diretório de Backup e Histórico de Planilhas Anteriores

Esta pasta armazena:
1. **Backups automáticos preventivos**: Sempre que uma nova planilha ativa é gerada ou uma reorganização de competência é executada, uma cópia com timestamp (`Planilha_Controle_VRE_Ativa_backup_AAAAMMDD_HHMMSS.xlsx`) é salva aqui.
2. **Planilhas de trabalho de meses ou anos anteriores**: Coloque aqui arquivos legados `.xlsx` ou `.xls` para importação histórica de atendimentos e mapeamento de CEPs via `Importar_Planilhas_Antigas.bat`.
